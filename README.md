# Tingy - Smart Image Compressor

Free online image compression tool. Compress JPG, PNG, WEBP, and AVIF images up to 20MB without losing quality.

## ✨ Features

- 🖼️ Support for JPG, PNG, WEBP, and AVIF formats
- 📦 Compress images up to 20MB
- 🎯 6 Smart Presets (Web, Social, Email, Print, Maximum, Custom)
- 🎨 Interactive Before/After Comparison Slider
- 📏 Optional Image Resizing with Aspect Ratio Lock
- 🎯 Target File Size Feature
- 🌓 Dark/Light Theme Support
- 📱 Fully Responsive Design
- 🔒 Secure - Images Never Stored
- 💯 Completely Free Forever

## 🚀 Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **UI Components**: shadcn/ui
- **Image Processing**: Sharp (libvips)
- **Animations**: Framer Motion
- **Notifications**: Sonner
