# Tingy – Smart Image Compressor

Tingy is a free online image compression tool designed to efficiently reduce image file sizes without compromising visual quality. It supports multiple formats and offers intelligent presets for various use cases including web, social media, email, and print workflows.

## Features

- Supports JPG, PNG, WEBP, and AVIF image formats  
- Compresses images up to 20MB  
- Six optimized compression presets (Web, Social, Email, Print, Maximum, Custom)  
- Interactive before/after comparison slider  
- Optional image resizing with aspect ratio locking  
- Target file size capability  
- Light and dark mode support  
- Fully responsive design  
- Secure processing with no image storage  
- Completely free to use

## Tech Stack

- **Framework:** Next.js 16 (App Router)  
- **Language:** TypeScript  
- **Styling:** Tailwind CSS v4  
- **UI Components:** shadcn/ui  
- **Image Processing:** Sharp (libvips)  
- **Animations:** Framer Motion  
- **Notifications:** Sonner

## Local Development Setup

Follow the steps below to install and run the project locally.

### Prerequisites
Ensure the following are installed:
- Node.js (LTS recommended)
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/tingy.git

# Navigate into the project directory
cd tingy

# Install dependencies
npm install
# or
yarn install
# or
pnpm install
```

### Development Server

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open your browser and navigate to:

```
http://localhost:3000
```

### Build for Production

```bash
npm run build
npm start
```
